Ask the user anything only with the AskUserQuestion tool, never in your reply. When you don't have that tool, as in a headless run, no one is there to answer: ask nothing, and do what each step says to do then.

Ask about what's still missing once, in one round of at most four questions across every issue, about what an agent would most need first. Each question offers the answers the context suggests, and an option to leave it open. Anything not asked, or left open, goes under Open questions.

A Problem you can't state, or a Done when you can't propose, isn't a gap but a reason not to write the issue: ask about it without the option to leave it open, and if the user still can't say, leave that issue unwritten.

When no one is there to answer, list every gap under Open questions, and leave unwritten any issue whose Problem or Done when is among them.
